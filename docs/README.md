# Top Tin Roofing website

Rebuild of https://toptinroofing.com. Next.js 16 (App Router), React 19, Tailwind CSS 4, MDX blog. Statically
generated, deployed on Vercel. Structure and conversion patterns follow the Delta Cleaning website (same owner).

## Run it

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build + SEO audit (fails on any error)
```

Node 22.18 or newer.

## Environment variables (Vercel)

| Variable | Purpose |
|---|---|
| `RESEND_API_KEY` | Email quote requests (with photos) to `LEAD_TO_EMAIL` (default toptinroofing@gmail.com) |
| `LEAD_FROM_EMAIL` | Sender, on a domain verified in Resend |
| `LEAD_WEBHOOK_URL`, `LEAD_WEBHOOK_SECRET` | Optional: also send leads to the TopTin System |
| `NEXT_PUBLIC_GTAG_ID`, `NEXT_PUBLIC_ADS_CONVERSION_ID` | Optional analytics and Google Ads conversion |
| `NEXT_PUBLIC_SITE_URL` | Only to override the canonical domain (default https://toptinroofing.com) |

Without `RESEND_API_KEY` or `LEAD_WEBHOOK_URL`, production leads are logged as errors and the form tells the visitor
to call. **Set one before going live.**

## Rules the build enforces

The SEO audit fails the build if any page: is missing a title, description, canonical, H1 or JSON-LD; has more than
one H1; shows a phone number other than 0480 095 902; is missing the QBCC licence or ABN; has no quote call to
action; uses forbidden claims ("best", "#1", "guarantee", "price match", "decades", unconfirmed counts and so on) or
an em dash; or has its main copy missing from the server HTML.
