# Photo shotlist

The site only uses real Top Tin photos. These would make the biggest difference, in order.

1. **Before and after pairs** (the top priority). Same angle, same spot, before the old roof comes off and after the
   new roof is finished. Street view and a closer roof view. Landscape, phone held level.
2. **Finished roofs from the street.** The whole house in good light, mid-morning or late afternoon. Note the suburb,
   roof type, colour and profile for each.
3. **Crew at work.** On the roof with safety gear visible (harness, edge protection, scaffold). Faces optional.
4. **Details.** New valleys, flashings, ridge capping, a whirlybird, gutters. Close and sharp.
5. **Colorbond colour samples** held against a house.
6. **Materials on site**: sheets, insulation blanket, delivery.
7. **The owner** for the About page. A simple, friendly photo in work gear.
8. **Clean up.** The yard and driveway after the job.

For each job, write down: suburb, what was removed (tile, iron, other), what went on (product, colour, profile),
and anything special (asbestos removal, valleys, two-storey). With that, each job can get its own project page.

Send photos as the original files (not screenshots, not compressed in a chat app). Run `npm run photos` after
adding new files to `research/photos` and listing them in `scripts/prepare-photos.mjs`.
