# Top Tin brand rule

Before making or changing any client-facing page, document, email, form, booklet or sign, read `docs/BRAND.md` and follow it exactly. The brand is "Plain Sight": Inter only (weights 400, 500, 600), navy and white with yellow used rarely, 8 px corners, no shadows, no gradients, nothing set below 12 px. The voice rules in the same file apply to every word.

Colour and type tokens as data: `docs/brand-tokens.json`. Keep `docs/BRAND.md` identical in `toptin-website` and `TopTin-System`.
